ada.services.checksum module

Checksum service: get the checksums that dCache stored for files.

dCache stores Adler32 and/or MD5 checksums. Checksums can be retrieved for files, for the files in a directory (recursively if wanted), or for the paths listed in a local file.

ada.services.events module

Event service: receiving dCache events and managing event channels.

dCache can report changes in the namespace (inotify events) as Server-Sent Events (SSE) on an event channel. This service creates and reuses channels, subscribes them to paths, and streams the events. ADA keeps the names of channels and the last received event in ~/.ada/channels (see AdaState), so a stream can be resumed.

Not yet available through AdaClient.

ada.services.staging module

Staging service: bringing files from tape to disk, and releasing them.

Staging creates a bulk request in dCache that copies files from tape to disk and pins them there for a while. Unstaging releases the pins, so dCache may remove the disk copies. Both run in the background in dCache; their bulk requests can be followed and deleted.

poolgroups_for_path(path)

Resolve which pool group(s) serve a namespace directory.

Follows the same chain dCache itself uses to pick a pool group for a path: storage class + HSM identify a storage unit, which belongs to a unit group, which is attached to link(s), which are attached to pool group(s).

Only directories are accepted. When a file is moved, its storage class/HSM is updated to match the new directory, but its data stays put in the pool group it was originally written to. So a moved file’s storage class/HSM may point to a different pool group than the one its data actually lives in, making pool group resolution for a file unreliable.

Parameters:

path (str) – dCache path of a directory.

Returns:

Names of the pool groups, to use with space().

Raises:

  • AdaValidationError – If path is a file, not a directory.

  • AdaNotFoundError – If the path has no storage class/HSM, or no unit group/link/pool group could be found for it.

Return type:

list[str]

quota()

ada.services.transfer module

Transfer service: upload and download file content via WebDAV.

The dCache REST API can only manage metadata; actual file content is transferred through a WebDAV door (see ada.webdav). This service applies the same safety rules as the Bash version: no silent overwrites, no downloading directories/symlinks, and, importantly, it refuses to download a file that’s only on tape (nearline), since dCache would otherwise silently stage it while the connection sits there waiting, which can take anywhere from minutes to days.

Upload a local file to dCache.

  • AdaTransferError – On a checksum mismatch, if no WebDAV door is found, or if a redirect is refused.

  • AdaAPIError – If the WebDAV door returns an HTTP error.

Return type:

Download a file from dCache.

  • AdaAPIError – If the WebDAV door returns an HTTP error.

  • regex (str) – Regular expression (Python syntax). A value matches when the pattern is found anywhere in it.

  • recursive (bool) – Also search subdirectories.

  • all_keys (bool) – Match the values of all attributes, not only key.

Returns:

A tuple for each file with matching attributes, with the file path and a dict of the matching attributes.

Raises:

  • AdaPathError – If the path is a file.

  • re.error – If the regular expression is invalid.

Return type:

list[tuple[str, dict[str, str]]]
