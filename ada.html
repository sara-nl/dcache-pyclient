ada.api module

Low-level HTTP client for the dCache REST API.

Wraps httpx and takes care of authentication, parsing JSON responses, turning HTTP errors into ADA exceptions, debug logging of requests, and streaming Server-Sent Events. Library users normally use AdaClient instead.

ada.auth module

Authentication for ADA, and inspection of tokens.

Each authentication method is an AuthProvider: a bearer token (TokenAuth, TokenFileAuth, TokenOidcAgentAuth), a netrc file (NetrcAuth) or an X.509 proxy certificate (ProxyAuth). resolve_auth() picks the method from, in order of precedence (matching the Bash version):

  1. Explicit arguments (highest)

  2. Environment variables

  3. Config file values (lowest)

The module also decodes JWT/OIDC tokens and macaroons, checks their expiry and permissions, and checks a macaroon’s IP caveat against this system’s public IP address.

validate(command=None)

Check that the proxy does not expire within 60 seconds.

A VOMS proxy has two, potentially different, validity windows: the X.509 certificate’s own notAfter, and (if present) the embedded VOMS attribute certificate’s attrCertValidityPeriod, which the VOMS server controls independently of the certificate lifetime requested at voms-proxy-init time. Both are checked; whichever expires first determines the effective expiry. With several certificates in the file, the earliest expiry counts.

Parameters:

command (str | None) – Not used; a proxy has no operation-specific permissions to check.

Raises:

  • AdaTokenExpiredError – If the proxy or its VOMS attributes have expired or expire within 60 seconds.

  • AdaAuthError – If the file contains no certificates.

class ada.client.AdaClient(api=None, tokenfile=None, token=None, tokenclient=None, netrc=None, proxy=None, igtf=None, config_paths=None, verify=True, debug=False)

Bases: object

High-level client for the dCache REST API.

Creating a client loads the configuration, picks an authentication method and checks the credentials (e.g. that a token has not expired), so problems show up right away rather than at the first request.

Configuration is read from, in order of increasing precedence: the bundled defaults, /etc/ada.conf, ~/.ada/ada.conf, environment variables (such as ada_api) and finally the arguments given here.

Authentication uses the first method found, in this order:

  1. Arguments: token, tokenfile, tokenclient, netrc, proxy.

  2. Environment variables: $BEARER_TOKEN, $ada_tokenfile, $ada_tokenclient, $ada_netrcfile.

  3. Config file settings: tokenfile, tokenclient, netrcfile.

Use the client as a context manager, or call close() when done, to close the network connections.

Parameters:

  • api (Optional[str]) – URL of the dCache REST API, e.g. "https://dcache.example.org:3880/api/v1". Must start with https://. Overrides the api config setting.

  • tokenfile (Optional[str]) – File with a bearer token (macaroon or OIDC token): either an rclone config file with a bearer_token line, or a file with only the token. Must not be readable or writable by others.

  • token (Optional[str]) – Bearer token (macaroon or OIDC token) as a string.

  • tokenclient (Optional[str]) – Name of an oidc-agent account to get OIDC tokens from. Needs oidc-agent to be installed and running, and pip install 'dcache-pyclient[oidc-agent]'.

  • netrc (Optional[str]) – Netrc file with a username and password for the API host. An empty string means ~/.netrc. Must not be readable or writable by others.

  • proxy (Optional[str]) – X.509 proxy certificate file. An empty string means $X509_USER_PROXY, or /tmp/x509up_u<uid> if that is not set.

  • igtf (Optional[bool]) – For proxy authentication, also trust the IGTF Grid CA certificates (in $X509_CERT_DIR, by default /etc/grid-security/certificates) when verifying the server. Set to False when the server has a regular certificate, e.g. from Let’s Encrypt. Overrides the igtf config setting.

  • config_paths (Optional[list[str]]) – Config files to read instead of the default ones, highest precedence first.

  • verify (bool) – Verify the server’s TLS certificate. Only set to False for testing: it makes the connection insecure.

  • debug (bool) – Log the HTTP requests and responses (at debug level, on the ada logger).

Raises:

  • AdaConfigError – If the API URL does not start with https://.

  • AdaAuthError – If no authentication method is found, or the credentials can’t be read (e.g. a missing proxy file).

  • AdaTokenExpiredError – If the token or proxy has expired, or expires within 60 seconds.

  • AdaSecurityError – If a token, netrc or config file is readable or writable by others.

  • FileNotFoundError – If the token or netrc file does not exist.

  • RuntimeError – If tokenclient is used but the oidc-agent library is not installed.

ada.x509utils module

Minimal DER/ASN.1 helpers for X.509 proxy certificate validation.

Implements just enough of DER to answer two questions about a grid proxy certificate, without depending on an external crypto library or shelling out to voms-proxy-info:

  1. When does the X.509 certificate itself expire (tbsCertificate.validity)?

  2. If it carries a VOMS attribute certificate (the non-critical extension with OID 1.3.6.1.4.1.8005.100.100.5), when do the VOMS attributes (FQANs/roles) expire? That is a separate validity window (AttCertValidityPeriod per RFC 3281), often different from the certificate’s own validity.

This is not a general-purpose ASN.1 library: it only decodes tag/length/ value structure generically, and locates the fields we need by shape (e.g. “the SEQUENCE holding exactly two GeneralizedTime values”) rather than by fully modelling the X.509 or RFC 3281 schemas. VOMS attribute certificates in particular use several CHOICE types (holder, issuer) that are awkward to model fully but irrelevant to finding the validity period.

Bases: object

High-level client for the dCache REST API.

Creating a client loads the configuration, picks an authentication method and checks the credentials (e.g. that a token has not expired), so problems show up right away rather than at the first request.

Configuration is read from, in order of increasing precedence: the bundled defaults, /etc/ada.conf, ~/.ada/ada.conf, environment variables (such as ada_api) and finally the arguments given here.

Authentication uses the first method found, in this order:

  1. Arguments: token, tokenfile, tokenclient, netrc, proxy.

  2. Environment variables: $BEARER_TOKEN, $ada_tokenfile, $ada_tokenclient, $ada_netrcfile.

  3. Config file settings: tokenfile, tokenclient, netrcfile.

Use the client as a context manager, or call close() when done, to close the network connections.

Parameters:

  • api (Optional[str]) – URL of the dCache REST API, e.g. "https://dcache.example.org:3880/api/v1". Must start with https://. Overrides the api config setting.

  • tokenfile (Optional[str]) – File with a bearer token (macaroon or OIDC token): either an rclone config file with a bearer_token line, or a file with only the token. Must not be readable or writable by others.

  • token (Optional[str]) – Bearer token (macaroon or OIDC token) as a string.

  • tokenclient (Optional[str]) – Name of an oidc-agent account to get OIDC tokens from. Needs oidc-agent to be installed and running, and pip install 'dcache-pyclient[oidc-agent]'.

  • netrc (Optional[str]) – Netrc file with a username and password for the API host. An empty string means ~/.netrc. Must not be readable or writable by others.

  • proxy (Optional[str]) – X.509 proxy certificate file. An empty string means $X509_USER_PROXY, or /tmp/x509up_u<uid> if that is not set.

  • igtf (Optional[bool]) – For proxy authentication, also trust the IGTF Grid CA certificates (in $X509_CERT_DIR, by default /etc/grid-security/certificates) when verifying the server. Set to False when the server has a regular certificate, e.g. from Let’s Encrypt. Overrides the igtf config setting.

  • config_paths (Optional[list[str]]) – Config files to read instead of the default ones, highest precedence first.

  • verify (bool) – Verify the server’s TLS certificate. Only set to False for testing: it makes the connection insecure.

  • debug (bool) – Log the HTTP requests and responses (at debug level, on the ada logger).

Raises:

  • AdaConfigError – If the API URL does not start with https://.

  • AdaAuthError – If no authentication method is found, or the credentials can’t be read (e.g. a missing proxy file).

  • AdaTokenExpiredError – If the token or proxy has expired, or expires within 60 seconds.

  • AdaSecurityError – If a token, netrc or config file is readable or writable by others.

  • FileNotFoundError – If the token or netrc file does not exist.

  • RuntimeError – If tokenclient is used but the oidc-agent library is not installed.

Example:

from ada import AdaClient

with AdaClient(api="https://dcache.example.org:3880/api/v1",
               tokenfile="~/macaroon.conf") as client:
    info = client.whoami()
    print(info.username, info.home)
